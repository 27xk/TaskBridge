# 桌面工作流体验设计

日期：2026-10-10。范围：用户提出的六项桌面改进，沿用 Vue 3 / Electron 本地优先架构与安卓视觉语言。

- **共享草稿与可靠录入**：今日快速输入和详细编辑共用草稿，标题、正文及已填元数据往返保留。保存成功才清空，失败允许原样重试。现有任务编辑独立于新建草稿。
- **明确连接状态**：托盘、悬浮窗统一状态语义，disconnected 绝不匹配 connected。
- **就地撤销**：完成、删除、改期、批量操作后显示可点击撤销提示。按操作记录字段差异，撤销只恢复对应字段，保留当前同步版本和其他后续编辑。主进程在 SQLite 事务中同时核对工作区、完整任务快照和同步队列 ID，原子提交任务与队列；并发变化时重新读取计算。批量为一个撤销组，部分失败保留已成功项撤销。永久删除维持确认且不提供撤销。
- **批量排期**：选择工具栏提供安排今天、日期、优先级；日期按显示时区处理，已有提醒与截止关系保持一致。
- **快捷键**：Ctrl+Shift+Space 默认只显示悬浮窗并聚焦录入，不广播。Ctrl+F 聚焦任务搜索；Ctrl+Enter 保存当前输入/编辑，输入法组合期间不触发。
- **宽屏布局**：内容宽度 1280 px 起使用列表加右侧详情，详情独立滚动、列表可连续选任务；窄屏使用抽屉。切任务保护未保存编辑。主窗恢复普通尺寸、坐标、最大化，浮窗恢复坐标，屏幕变更后保持可见。
- **工作现场**：按工作区保存搜索、筛选、滚动位置。常用视图保存动态筛选条件，支持本周高优先级、项目待办及自定义组合；账号之间隔离。
- **视觉与性能**：沿用青绿强调色、中性表面和清晰标题。仅侧栏、工具栏、编辑容器使用轻量玻璃，提供紧凑/舒适密度和关闭效果入口。保留禁用 GPU 的默认兼容路径。根据实测结果，软件渲染只使用透光色层和高光；硬件合成可用时启用 8 px 背景模糊。

验证包含定向行为测试、Vue 类型检查、构建、隔离 Electron 的真实录入/撤销/筛选/布局/快捷键回归，以及效果开关对照。现有改动保留，基线保存于 desktop/tmp/ux-20261010。
