# Android 导航与同步入口微调

用户要求：右上角直接显示“立即同步”，今日 / 全部 / 设置使用悬浮液态玻璃，并减小页面切换的布局突变。

采用现有绿色主题、独立背景采样和 Material 3 导航。恢复 `TaskHomeScaffold` 的 `LiquidGlassBackdrop`，导航外包 `GlassStyle.Elevated` 表面，内部 Material 导航保持透明。手机导航保留两侧 16 dp、底部 12 dp 间距；宽屏保留悬浮导航轨。

三个页面复用同一框架、标题组件与 20 dp 内容边距。标题保持单行并在窄屏大字体时省略，副文本统一保留两行，避免任务统计与设置分类的不同长度挤动内容。设置页持续显示导航并正确选中“设置”，保留返回与系统返回；设置页不显示新建按钮。导航图标与文字始终显示，选中状态不改变控件尺寸。顶层页面使用 220 ms 淡入 / 140 ms 淡出；遵循 Compose 系统动画缩放。

在线模式的列表标题直接展示“立即同步”按钮，点击沿用 `viewModel.refresh()`。本机工作区继续使用现有登录同步入口。手机键盘展开时隐藏底部导航和新建按钮，关闭后恢复，保留输入区域。

验收：Android Debug 构建、JVM 回归和 Lint；API 35 硬件渲染检查手机明暗主题、宽屏导航轨、大字体、小屏布局；核对切换前后导航边界和触摸入口。
