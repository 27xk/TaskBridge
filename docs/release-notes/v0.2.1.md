# TaskBridge v0.2.1

本次更新强化跨端同步可靠性，降低大任务列表的数据传输和内存成本，并完善接口契约、监控和备份恢复工具。

## 更新内容

- 数据库版本条件阻止并发编辑覆盖；安全同步水位避免晚提交事务被增量拉取遗漏。
- REST、同步、导入和批量操作统一在事务提交后通知；Redis 分发支持多个后端进程，并隔离慢连接、坏连接与重复心跳。
- Windows 列表只常驻摘要，编辑、撤销、模板、导出和冲突处理按需读取完整记录。万条长正文合成任务的列表载荷由约 230.77 MB 降至 8.21 MB，减少 96.44%。
- Web/PWA 使用增量缓存对账、有界列表与稳定节点更新；修复回收站分页、离线统计和键盘焦点恢复。
- 提供完整 HTTP 响应契约、桌面生成网络类型和跨语言序列化样本。
- 三端节流上报同步健康；新增 Prometheus 告警、Grafana 面板、隔离备份恢复演练工具，以及数据与发布产物预算。
- 按进程和模块职责整理项目目录，保留现有离线工作区、任务数据和客户端操作流程。

## 升级说明

升级后端前请先备份数据库。本次需要迁移 `20261026_0014`，增加用户同步水位并保留 MySQL 微秒时间精度：

```sh
alembic upgrade head
```

官方 Docker 启动入口会自动执行迁移。使用已有部署配置更新镜像时，请保留原 `.env` 和数据卷，勿执行 `docker compose down -v`。

备份恢复演练可在具备 Docker 的环境显式运行：

```sh
python deploy/verify-backup.py <backup.sql.gz> --report drill.json
```

该工具使用隔离的临时 MySQL 容器，不会选择生产数据库；本次本地仅验证了工具行为，未执行真实恢复演练。
