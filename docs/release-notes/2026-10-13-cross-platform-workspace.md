# 跨端工作区与同步可靠性更新

这轮更新围绕日常录入、任务整理、离线恢复和大列表使用展开，同时修复了同步竞态与 Windows 打包启动问题。变更按功能提交到 `feat/desktop-focus-workspace`，不代表已发布新的安装包版本。

## 桌面工作台

- 快速录入、详细编辑与悬浮窗共享草稿，窗口重新打开后可恢复未提交内容。
- 支持批量安排、完成和删除、操作撤销、常用视图以及工作区筛选和滚动位置恢复。
- 宽屏可同时查看列表与详情，提供显示密度及玻璃效果设置，软件渲染保持兼容路径。
- 列表采用可见区域渲染和增量刷新；2,500 条合成任务仍完整可达，实测只挂载 14 行。
- 悬浮窗隐藏后停止无用刷新，闲置约 60 秒释放渲染进程，再次打开恢复草稿。

## Android

- 提供可降级的液态玻璃材质，调整设置分类、选择模式、登录与编辑反馈。
- 使用应用级容器和统一同步协调器，合并后台工作，按变更维护提醒及小组件。
- 筛选和搜索先在数据库执行，再按每页 100 条展示；5,001 条搜索和跨页访问已有回归覆盖。
- 旧编辑不能覆盖同步刚确认的任务身份，也不能恢复已经删除的任务；无日期的显式“今日”任务可正确进入小组件。

## Web 与服务端

- 同源 Web/PWA 通过 HttpOnly Cookie 恢复有效会话；主动退出撤销当前会话，离线恢复仍保留账号与缓存边界。
- 创建和编辑草稿按工作区、任务保存，快捷录入可进入详细编辑；菜单支持键盘关闭和焦点恢复。
- 完善批量操作、设置与支持入口、窄屏布局、两行正文摘要和深色按钮对比度。
- 修复延期后的提醒偏移、重复任务并发生成和同步交错；WebSocket 鉴权完成后及时归还数据库连接。
- 修复 Windows 打包过滤误删生产依赖入口，检查覆盖实际启动依赖与 SQLite 原生模块。

## 升级与部署

- **Android 最低系统版本调整为 Android 13（API 33）。** 较低版本系统不能安装本轮构建。
- Web 固定使用站点同源 API；Windows 和 Android 发布包使用构建时写入的服务地址。部署者需要配置 API / WebSocket 端点，服务地址改变后重新构建客户端。
- 新增退出当前会话接口，刷新请求兼容已有显式 Refresh Token，并支持浏览器 Cookie；API 契约见 [接口设计](../api-design.md)。
- 本轮产物仅用于验收，未执行签名发布。用户安装包仍以正式 Release 为准。

## 验证

最终验收包括桌面 251 项单测、38 项配置检查，Web 167 项测试和 56 项浏览器检查，后端 146 项测试，以及 Android 191 项 JVM 和 19 项设备测试。

性能数据来自本机隔离场景；Android PSS 为 Debug＋instrumentation 模拟器样本，不能外推真机或 Release。详细环境、复现方式和限制见 [跨端验收记录](../superpowers/specs/2026-10-13-cross-platform-remediation-validation.md)。
