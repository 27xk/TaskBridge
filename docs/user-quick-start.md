# TaskBridge 普通用户快速开始

这份说明只覆盖普通使用路径：打开已配置的客户端、登录、离线使用，以及清除这台设备数据前要确认什么。

如果管理员或部署者已经给你 Web 入口或客户端安装包及账号，直接登录，不需要处理网络地址细节。

## 先选路径

| 路径 | 适合谁 | 下一步 |
| --- | --- | --- |
| 已有服务入口 | 管理员提供 Web 入口或已配置的安装包及账号 | 直接登录 |
| 本机试用 | 想在自己的电脑上体验同步 | 按部署说明启动服务并打开本机 Web 入口 |
| 长期自托管 | 准备长期使用、多人使用或公网访问 | 配置服务，并为 Windows / Android 发布包写入服务地址 |

## 已有服务入口

如果管理员或部署者已经给你 TaskBridge 服务入口和账号，按这个顺序开始：

1. Web/PWA：打开部署者提供的 TaskBridge 访问地址。
2. Windows 或 Android：从 [GitHub Releases](https://github.com/27xk/TaskBridge/releases) 下载该版本提供的 Windows 安装包或已签名 Android APK。Windows 安装包当前未签名，安装时可能显示「未知发布者」；当前版本没有对应客户端文件时先使用 Web/PWA。
3. 在登录页输入账号和密码。服务地址由 Web 访问入口或安装包决定；连接失败时检查网络，持续失败请联系管理员。

登录成功后，默认从“今日”开始。新建任务时只填标题就能保存，也可以直接输入“明天下午 3 点写周报 #工作 P3”让客户端识别时间、标签和优先级。

Windows 和 Android 的时间简写支持 `09:30 开会`、`明天 9 开会` 和 `下午3点 开会`。普通数量（如 `购买 2 个苹果`、`苹果数量 2`）会保留在标题中；只有日期相关或带有时钟、时段标记的数字才会作为时间解析。

编辑任务时，标题是默认主输入；备注和清单按“添加备注和清单”展开，日期、提醒和优先级按“时间与安排”展开，标签、重复和模板等低频设置按“更多”展开。任务列表可以进入选择模式，批量完成或删除当前可见任务；删除和永久删除仍会要求确认。

Windows 和 Android 在设置页按分类切换内容。Web 任务侧栏提供今日、本周、模板、项目和标签等任务入口；账号安全、通知、统计、同步排障和本机备份统一从“设置与支持”入口打开。

Windows 设置中的“项目 / 标签维护”属于低频工具，进入对应分类后默认收起；需要批量改名或清理元数据时再展开。

“稍后 1 小时”会把提醒和任务优先级一起推迟，到时间后再次提醒。Windows 和 Android 将今日任务“推迟到明天”时，会同步调整已有的单独提醒并移回收件箱，不再继续显示在今日列表；原本没有单独提醒的任务仍使用截止时间。

## 忘记密码

Web、Windows 和 Android 的登录页都会显示忘记密码说明。TaskBridge 当前不提供邮件自助找回；无法登录时，请联系这套 TaskBridge 的服务器管理员重置密码。管理员重置后，该账号原有登录会话会全部失效，需要使用新密码重新登录。

如果仍能登录，可以在客户端“账号安全”中使用当前密码修改密码，不需要管理员处理。

## 没有服务入口

如果你不是部署者，请先向管理员或部署者索取 Web 访问地址或对应服务的客户端安装包及账号。

如果只是想先在自己的电脑上试用，按 [部署说明的本机试用](../deploy/README.md#本机试用) 启动服务，再打开本机 Web 入口。

如果准备长期使用、多人使用或公网访问，先按 [部署说明](../deploy/README.md) 完成生产自托管，并在发布 Windows / Android 客户端时写入正式服务地址。

## 本机试用时的地址

电脑上本机试用时，直接打开 Web 入口；手机或另一台电脑访问时，应打开运行服务电脑提供的 Web 地址。开发版客户端仍可在调试界面修改服务地址。

- Web：打开 `http://127.0.0.1:8080`，页面与 API 使用同一入口。
- Android 真机或另一台电脑上的 Web：打开 `http://<运行服务电脑的局域网 IP>:8080`。
- Windows / Android 开发版：在构建或调试时配置对应地址；发布包中的地址固定在安装包内。

Release Compose 的 `8080` 是普通客户端的统一入口。`8000` 只用于开发或高级直连，只有部署者明确要求时才使用。

如果手机连不上，先确认手机和电脑在同一个局域网，再确认打开的是运行服务电脑的 Web 地址。

## 离线使用

第一次使用需要先登录并完成一次任务同步。登录会话仍然有效时，离线可以继续查看、新增、编辑和完成任务，这些修改会保存在本机。

Windows 和 Android 的会话自然失效后，登录页会提供本机工作区入口。进入后仍可查看和修改缓存任务，但不会连接服务器或上传修改；点击“登录并同步”，使用同一服务器上的账号登录后才会上传待同步修改。主动点击“退出登录”会清除工作区身份，不等同于会话自然失效。

同源 Web/PWA 登录成功时，服务器会写入 HttpOnly Cookie。只要该 Cookie 有效且用户没有主动退出，关闭浏览器后重新打开会自动恢复登录和在线同步，不需要再次输入密码。Web 固定连接当前站点的同源 API 入口。

Cookie 失效、被管理员撤销或自动恢复失败后，如果当前服务器与上次同步来源一致、且该账号的本机缓存已经完整初始化，登录页会显示“继续离线使用”：

1. 点击“继续离线使用”打开上次账号在这台设备上的任务。
2. 离线修改会继续进入本机待同步队列。
3. 网络恢复后点击顶部“登录并同步”，使用同一账号重新登录。
4. 登录成功后，TaskBridge 才会把待同步修改发送到服务器。

如果预期看到恢复入口却没有显示，请确认当前打开的是上次使用的 TaskBridge 站点。仅保存过账号信息、但从未完成任务缓存初始化时，不会提供空的恢复入口。

在线状态下主动点击“退出”会尝试撤销当前服务端会话、清除浏览器 Cookie，并移除离线恢复身份。如果页面显示“本机已退出，但服务器未确认撤销此会话”，说明本机退出已经完成，但服务端暂时没有确认；网络恢复后重新登录，再到“账号安全”检查登录设备。“清除此设备数据”会先删除本机缓存，再移除本机身份；如果其他 TaskBridge 标签页正在使用同一份本机数据库，页面会等待标签页关闭后自动继续。普通的断网、服务器暂不可用或会话过期不会删除本机任务缓存。

如果同一条任务在多台设备上都改过，客户端会显示冲突对比。先比较“这台设备”和“同步来的版本”，再选择保留哪一版。

在 Android 本机工作区中，尚未同步的任务可以直接永久删除；已经同步到服务器的任务需要先联网。离线点击永久删除时，TaskBridge 会保留任务并提示联网，不会显示为删除成功。

通过局域网明文 HTTP 打开的 Web 页面仍可正常管理任务。浏览器可能不允许这类页面安装为 PWA 或使用离线页面缓存；这不影响普通网页和已安装客户端连接。

## 数据与备份

导出备份会保存这台设备上的本机任务数据，适合换设备、切账号或排查前留一份副本。

清除这台设备数据只会删除当前设备上的登录状态、本机缓存和等待同步的修改，不会删除服务器上的任务。清除前先确认没有待同步、同步失败或冲突的任务；不确定时先导出备份。

## 常见入口

- 服务地址变更：联系管理员获取新 Web 入口或更新后的客户端安装包。
- 查看同步问题：出现异常时使用任务区提示，或打开“设置与支持 / 同步问题”；同步正常和等待联网自动同步不会被显示成故障。
- 整理项目 / 标签：设置页展开项目和标签维护。
- 连接失败、手机访问本机服务、清除本机数据前检查：参考 [常见问题](./troubleshooting.md)。
